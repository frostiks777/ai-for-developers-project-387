# Календарь звонков

Контекст сервиса онлайн-записи на звонок с организатором: гость выбирает свободное время, оставляет контакты и получает подтверждение; организатор управляет доступностью и встречами.

## Language

### Роли

**Организатор**:
Человек, который открывает время для записи и принимает звонки.
_Avoid_: Хост, владелец, автор

**Гость**:
Человек, который записывается на звонок, не имеет аккаунта и не проходит авторизацию.
_Avoid_: Клиент, пользователь, посетитель

### Запись

**Тип встречи**:
Вид брони, который предлагает организатор (название, описание, длительность). В MVP — один неявный тип.
_Avoid_: Событие, услуга, категория

**Слот**:
Конкретный промежуток времени, который организатор открыл для записи.
_Avoid_: Окно, тайм-слот, интервал

**Бронь**:
Запись гостя на один слот вместе с контактами гостя и выбранным типом встречи. Один слот — не более одной активной брони, в том числе для разных типов встреч.
_Avoid_: Запись, резервация, слот

**Статус брони**:
Состояние брони: `confirmed` (активна, занимает слот) или `cancelled` (отменена, слот освобождён). Отмена меняет статус, а не удаляет бронь.
_Avoid_: Флаг, состояние

**Встреча**:
Сохранённая бронь в календаре организатора и на экране успеха гостя.
_Avoid_: Запись, звонок

### Доступность

**Правило доступности**:
Набор условий, по которым из календаря собираются слоты: рабочие дни, диапазоны времени, длительность слота, буфер, минимальный запас и горизонт.
_Avoid_: Настройки, расписание

**Диапазон доступности**:
Непрерывный интервал времени внутри рабочего дня, открытый для записи; у одного дня может быть несколько диапазонов.
_Avoid_: Окно, смена

**Токен брони**:
Секретная строка из ссылки, по которой гость без авторизации может посмотреть, перенести или отменить свою бронь.
_Avoid_: Ключ, секрет, идентификатор

### Интерфейс

**Страница бронирования**:
Экран, где гость выбирает слот и оставляет контакты.
_Avoid_: Форма, витрина

**Главная страница**:
Витрина сервиса, которая рассказывает о нём и ведёт на страницу бронирования.
_Avoid_: Лендинг, homepage

**Панель организатора**:
Экран организатора со списком встреч и настройкой доступности.
_Avoid_: Админка, дашборд
