## 3. Панель управления организатора (Host Dashboard) — Приоритет P1

### 3.1. Страница настройки доступности: `/admin/availability`
- [ ] **Форма расписания по дням недели (`WeeklyScheduleForm`):**
  - [ ] Переключатели (Toggle) для каждого дня: Понедельник — Воскресенье.
  - [ ] Динамическое добавление/удаление интервалов времени (например: `09:00 - 13:00` и `14:00 - 18:00`).
  - [ ] Кнопка «Скопировать расписание понедельника на все будние дни».
- [ ] **Форма правил бронирования (`BookingRulesForm`):**
  - [ ] `slot_duration`: селектор продолжительности встречи (15, 30, 45, 60 мин).
  - [ ] `buffer_before` и `buffer_after`: время перерыва между слотами (0–60 мин).
  - [ ] `min_booking_notice`: минимальный срок до встречи (например, не раньше чем за 2 часа).
  - [ ] `max_future_days`: глубина календаря (например, доступность на 14 / 30 / 60 дней вперед).
