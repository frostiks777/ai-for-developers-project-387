## Правила

- **Сюда не добавляют новые планы.** План, который ещё исполняется, живёт в `docs/` (`todo.md`,
  `course-steps.md`, `design/v2/implementation-plan.md`) и переезжает сюда только когда выполнен.
- **Архивные ADR — не канон.** Черновики `design/v2/adr/` заморожены; решения живут в
  [`../adr/`](../adr/README.md). Статус Superseded у ADR-0017, 0019 — нормальный, файлы остаются в `adr/`,
  потому что на них ссылаются живые документы.
- **Правки в архив не вносят**, кроме исправления битых ссылок и шапки-статуса. Расхождения архива с кодом —
  норма: это снимок момента.
