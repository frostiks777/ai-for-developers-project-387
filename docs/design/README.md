## v1 A + D (история)

Первый редизайн: десктоп — вариант **A** (три колонки), телефон — **D** (лента дат и нижняя панель), светлая и тёмная темы. Визуальный слой v2 заменяет его ([ADR-0023](../adr/0023-redesign-v2-mint.md)); структура и токены v1 остаются справочными.
