# Контракт с тестами (v2)

Редизайн v2, в отличие от v1, меняет не только вид, но и сценарий записи: время за гостя больше не выбирается, форма на десктопе живёт в колонке, а не в диалоге. Поэтому часть тестов меняется. Всё, что здесь не перечислено как изменяемое, должно проходить **без правок**. Удалять проверки без замены нельзя: каждая удалённая проверка должна иметь эквивалент в новом тесте.

Автопроверку Хекслета (`.github/workflows/hexlet-check.yml`) не видно, поэтому маршруты и ключевые тексты по возможности сохраняются (список ниже).

## 3. Новые тесты (обязательные)

- `server/admin-auth.test.ts`: `GET /api/v1/hosts/:slug/bookings` → 401 без пароля и 200 с паролем; `POST` без пароля не 401; `GET /events` → 302 на `/admin/bookings`.
- `server/availability.test.ts`: генерация в `Europe/Moscow` (10:00 → 07:00Z), `UTC` без изменений, переход на летнее время в `Europe/Berlin`.
- `server/availability-settings.test.ts`: PUT с новым `timeZone` меняет пояс хоста.
- `src/utils/timezone.test.ts`: `formatWeekdayShort('2026-09-28') === 'Пн'`; `formatZoneShort('Europe/Moscow')` → «по Москве (UTC+3)».
- `two-week-grid.test.tsx`, `slot-groups.test.tsx`, `week-grid.test.tsx`, `view-toggle.test.tsx` (сохранение в `localStorage`), `booking-wizard.test.tsx`, `slot-suggestions.test.tsx`, `guest-message.test.ts`, `ambient-background.test.tsx`.

## 4. Заглушки

`src/test/setup.ts` уже подменяет `matchMedia` (десктоп по умолчанию). Для `navigator.clipboard` в тестах копирования — `vi.stubGlobal`/`Object.defineProperty` локально в тесте. `localStorage` в jsdom есть; очищать в `afterEach`.
