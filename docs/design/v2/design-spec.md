# Дизайн-спецификация v2: «Мята и солнце»

Источник истины по внешнему виду и поведению интерфейса для редизайна v2. Порядок работ — в [`implementation-plan.md`](implementation-plan.md), обоснование каждой правки — в [`ux-cases.md`](ux-cases.md), что можно и нельзя менять в тестах — в [`test-contract.md`](test-contract.md).

Эталоны: `screenshots/*.png` (как должно выглядеть) и `mockups/*.html` (размеры и цвета в inline-стилях; открывать в браузере). Макеты — эталон вида, а не код: в приложении всё делается Tailwind-классами на токенах, inline `style={{}}` запрещены (`docs/conventions.md`).

Данные в макетах условные: 28 сентября 2026, пояс Europe/Moscow, слоты 13:00–20:20 через 40 минут, заняты 13:00 и 15:40. Имена гостей в макетах вымышленные.

---

## 0. Принципы

1. **Гость сам выбирает время.** Ничего не выбирается за него: ни слот, ни «первый свободный». Кнопка записи появляется после выбора.
2. **Время всегда с поясом.** Где бы ни стояло время встречи, рядом подписан пояс гостя: «по Москве (UTC+3)».
3. **Один яркий цвет — одно значение.** Жёлтый `highlight` означает «ваш выбор и главное действие». Он есть только у выбранного времени, у главной кнопки экрана и у плашки «Ближайшее свободное».
4. **Недоступное видно, но не кликается.** Занятое время и выходные не прячутся: они зачёркнуты или приглушены и подписаны.
5. **Необратимое — красное и с подтверждением.** Отмена встречи — `destructive`, всегда со вторым шагом.
6. **Контакты гостей видит только организатор.**

## 1. Основы

### 1.1 Цвет

Все цвета — токены из [`tokens.css`](tokens.css). Светлая и тёмная темы остаются (переключатель из v1). Hex в компонентах запрещены.

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `background` | #F4F1EA | #111214 | основа под живым фоном |
| `card` | #FFFFFF | #1B1D21 | карточки; в стекле — с прозрачностью `--glass` |
| `primary` / `primary-foreground` | #0F766E / #FFF | #5FD4C0 / #06201C | выбранный день, рамка свободного времени, ссылки, активный пункт меню |
| `accent` / `accent-foreground` | #D7F0E8 / #0B5A53 | #173A35 / #8FE6D2 | доступные дни, сводка выбранного времени, выбранный формат |
| **`highlight` / `highlight-foreground`** | #FFC53D / #2B1D00 | #FFC53D / #2B1D00 | **выбранное время, главная кнопка, плашка «Ближайшее свободное»** |
| `destructive` | #B42318 | #F2857A | отмена встречи, ошибки полей |
| `disabled-foreground` | #A29A92 | #6B707A | занятое время, выходные, дни вне окна |
| `blob-1…4` | мята, персик, небо, солнце | приглушённые версии | пятна живого фона |

Контраст (WCAG AA ≥ 4.5:1): `highlight-foreground` на `highlight` — 10.4; `primary-foreground` на `primary` — 5.47; `accent-foreground` на `accent` — 6.73; `muted-foreground` на стекле — 7.05. Остальные пары — как в v1 (`docs/design/README.md`).

Правило акцента: `bg-highlight` не используется для навигации, выбранного дня, бейджей статуса и декора. Если на экране две главные кнопки, это ошибка дизайна: одна из них становится `outline`.

### 1.2 Живой фон

Компонент `AmbientBackground` (`src/components/ambient-background.tsx`) рендерится один раз в `AppShell`:

```tsx
<div aria-hidden="true" className="ambient">
  <span className="ambient-blob -left-[12%] -top-[18%] w-[max(52vw,300px)] bg-blob-1 animate-blob-a" />
  <span className="ambient-blob -right-[10%] top-[8%] w-[max(46vw,260px)] bg-blob-2 animate-blob-b" />
  <span className="ambient-blob bottom-[-26%] left-[18%] w-[max(50vw,280px)] bg-blob-3 animate-blob-c" />
  <span className="ambient-blob bottom-[-8%] right-[14%] w-[max(30vw,180px)] bg-blob-4 opacity-70 animate-blob-d" />
</div>
```

- Слой `fixed inset-0 z-0`, контент страницы — в обёртке `relative z-10`.
- Пятна размыты на 64 px и медленно плывут (19–27 с, `alternate`).
- При `prefers-reduced-motion: reduce` анимация выключена (правило есть в `tokens.css`).
- Зерно из макетов в коде не делаем: на реальных экранах оно даёт муар при прокрутке.
- В тестах (jsdom) компонент рендерится, но ни на что не влияет; `aria-hidden` обязателен.

### 1.3 Стекло

- Карточки первого уровня (колонки записи, панели, карточки организатора) — класс `glass` + `rounded-card shadow-glass`.
- Шапка — `glass-bar`.
- Поля ввода, кнопки, ячейки дней и времени **не** стеклянные: у них сплошной фон, иначе падает контраст.
- В тёмной теме рамка стекла — `border-white/10`.

### 1.4 Шрифты, размеры, радиусы

Шрифты и шкала — как в v1: Golos Text для интерфейса, Lora для крупных заголовков. Новые размеры:

| Элемент | Классы |
|---|---|
| Ячейка дня (A) | `h-[60px] rounded-xl`, число `text-lg font-bold`, подпись `text-[11px]` |
| Кнопка времени (A, десктоп) | `h-[46px] rounded-[10px] text-[15px] font-semibold` |
| Кнопка времени (C2, телефон) | `h-[52px] rounded-[14px] text-base font-bold` |
| Ячейка недели (B) | `h-11 rounded-[9px] text-sm font-semibold` |
| Главная кнопка | `h-[52px] rounded-xl text-base font-semibold` (телефон `h-14 rounded-[14px] text-[17px]`) |
| Поле ввода | `h-11` (десктоп), `h-[52px] text-base` (телефон) |
| Сегмент «Дни / Неделя» | контейнер `h-9 rounded-full bg-secondary p-[3px]`, вкладка `h-[30px] px-3.5 text-[13px]` |

Цели касания ≥ 44×44 px везде (поля времени в «Доступности» — тоже).

### 1.5 Иконки

`lucide-react`, `strokeWidth={1.8}`, 16–18 px. Новые: `Check` (выбранное время), `Sparkles` не используем. Иконка без подписи — только с `aria-label`.

### 3.2 Запись, десктоп, вид «Неделя» — вариант B (`screenshots/B-booking-week.png`)

**Левая карточка «Ваша встреча»**
- «← Все мои встречи» (`/my`), заголовок Lora 30 px «Ваша встреча» и бейдж статуса «подтверждена» (`bg-success-soft text-success`) или «отменена» (`bg-secondary text-muted-foreground`).

При нажатии блок раскрывается на месте (не модалка) `bg-destructive/5 border-destructive-border rounded-2xl p-4`: заголовок «Вы уверены, что хотите отменить бронирование?», текст «Встреча 28 сентября в 14:20. Время освободится для других. Вернуть эту запись будет нельзя, только записаться заново.», поле «Причина отмены (необязательно)», кнопки `bg-destructive` «Да, отменить» и `outline` «Оставить встречу». Фокус переходит на заголовок блока.

**Правая карточка «Перенести на другое время» (отметки 1, 2)**
- Подзаголовок: «Текущее время: Пн, 28 сентября, 14:20. Выберите новое — ничего не изменится до подтверждения.»

Под карточками на десктопе — пунктирная заметка не нужна (она только на холсте).

### 3.6 Время заняли (409) — Б1 (`screenshots/case-06-slot-taken.png`)

При ответе `409 SLOT_TAKEN`:
1. Данные формы остаются.
2. `refetch()` слотов; занятое окно становится «занято».
3. Выбор слота снимается, форма показывает сообщение `role="alert"` под сводкой: «**Это время только что заняли.** Выберите соседнее — ваши имя и email сохранены.» (`bg-highlight/15 border-highlight/40 rounded-xl`).
4. Под сообщением — до трёх ближайших свободных окон того же дня (или следующего дня с окнами) кнопками как в `SlotGroups`. Клик выбирает слот, сообщение исчезает, кнопка снова «Записаться на 15:00».
5. Toast «Слот только что заняли» больше не показывается (дубль).

- Одна главная кнопка `bg-highlight` «Выбрать время» в первом экране. Нижний блок «Готовы выбрать время?» остаётся с `outline` кнопкой.

### 4.2 Обзор

- Баннер несовпадения пояса (отметка 3) — если пояс правил доступности ≠ поясу браузера: `bg-highlight/15 border border-highlight/50 rounded-2xl`, иконка `TriangleAlert`, текст «**Часы работы заданы в UTC.** Вы указали 10:00–18:00, а гости из Москвы видят 13:00–20:50.» и кнопка «Считать по Москве» (сохраняет пояс браузера в правила, см. план, этап 11). - Заголовок Lora 30 px — сегодняшняя дата «Пятница, 25 сентября».
- 4 плитки `glass rounded-2xl`: «Сегодня» (число встреч или «Выходной»), «Следующая встреча» («Пн, 13:00»), «На неделе 28.09–2.10» («3 встречи»), «Свободно на 14 дней» («113 окон»).
- «Ближайшие встречи» (отметки 1, 2) — ближайшие 7 дней, группы по дню. Строка: время 15/700 `tabular-nums`, имя, «Тип · длительность», шеврон. Клик раскрывает строку на месте (`aria-expanded`): Email, Телефон, Вопрос; кнопки «Скопировать текст для гостя», `outline` «Отменить» (`text-destructive`, с подтверждением как в 3.5). ## 5. Тексты

| Где | Текст |
|---|---|
| Кнопка записи | «Записаться на {HH:mm}»; без времени — «Выберите время»; отправка — «Отправка…» |
| Подсказка к неактивной кнопке | «Чтобы записаться, {заполните имя}, {email} и {отметьте согласие}» — только недостающее |
| Email, ошибка формата | «Похоже, адрес не полный: не хватает домена, например .ru» (если нет точки после @), иначе «Проверьте email: в нём должен быть знак @» |
| 409 | «Это время только что заняли. Выберите соседнее — ваши имя и email сохранены.» |
| Подсказка дня | «Нет подходящего времени? Во {вторник, 29 сентября}, свободно {11 окон} с {13:00}.» + «Показать {вторник}» |
| Ячейка без окон | «выходной» (Сб/Вс) или «—» |
| Занятое время | «занято», `aria-label="{HH:mm}, занято"` |
| Пояс | «по {Москве} (UTC+3)»: для частых зон — название города в предложном падеже (словарь в `utils/timezone.ts`: Москва, Санкт-Петербург → «по Москве», Калининград, Екатеринбург, Новосибирск, Владивосток, UTC → «по UTC»), для остальных — «по {IANA}» |

## 6. Доступность (a11y)

- Выбор дня и времени — нативные `button` с `aria-pressed`; группы времени — `role="group"` с `aria-labelledby` на подпись группы.
- Сегмент «Дни / Неделя» — `tablist`, стрелки ←/→ переключают вкладки.
- Раскрытие дополнительных полей и строк встреч — `aria-expanded` + `aria-controls`.
- Сообщение о 409 и ошибки полей — `role="alert"`; счётчики и «N свободных окон» — `aria-live="polite"`.
- Фокус после переходов мастера — на заголовок шага; после отмены — на заголовок «Встреча отменена».
- Анимация фона выключается при `prefers-reduced-motion`.

## 7. Адаптивность

| Ширина | Запись | Панель |
|---|---|---|
| < 1024 | мастер C1–C3 | табы разделов, одна колонка |

## 8. Отклонения от макетов (сознательные)

- Заголовок экрана успеха — «Встреча успешно запланирована!» вместо «Вы записаны» с макета C4: на этот текст опираются e2e и тесты.
- На C4 главное действие — «Добавить в Google Календарь» (ссылка), а не одна кнопка с меню: ссылку проверяют тесты, и она доступнее меню.
- На панели организатора кнопки «Перенести» у встречи нет (на макете D2 есть): перенос делает гость по своей ссылке. Если понадобится — отдельной задачей.
- Зерно фона из макетов не переносится (см. 1.2).
- Остальные палитры с доски `02-palette` не реализуются: только «Мята и солнце» + тёмная тема.
