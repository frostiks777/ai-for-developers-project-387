# Дизайн v2: «Мята и солнце»

Пакет для внедрения редизайна «Календаря звонков» агентом OpenCode (скилл `apply-design-v2`). Заменяет v1 (`docs/design/*`, ADR-0007) как текущий дизайн; v1 остаётся историей.

## Что меняется, коротко

- **Безопасность.** Имена и email гостей больше не публичны: список броней в API закрыт паролем, `/events` перенесена в панель ([ADR-0022](adr/0022-private-bookings-list.md)).
- **Время.** Слоты генерируются в поясе организатора, у каждого времени подписан пояс гостя, исправлены дни недели в ленте на телефоне ([ADR-0024](adr/0024-slots-in-host-timezone.md)).
- **Запись.** Время не выбирается за гостя. На десктопе всё на одном экране, два вида: «Дни» и «Неделя». На телефоне — мастер из трёх шагов. Форма в колонке, а не в модалке; при конфликте данные сохраняются и предлагаются соседние окна ([ADR-0023](adr/0023-redesign-v2-mint.md)).
- **Перенос и отмена** — одна страница «Ваша встреча» с подтверждением.
- **Панель** — отдельные экраны и «Обзор».
- **Вид.** Мятный основной цвет, яркий жёлтый акцент для выбора и главного действия, живой пастельный фон, карточки из матового стекла, светлая и тёмная темы.

Тёмная тема на макетах не нарисована: она получается из тех же токенов (`.dark` в `tokens.css`). Сверять её с правилами §1 спеки: нет белых рамок и вспышек, стекло тёмное, жёлтый акцент тот же.

Чёрные кружки с номерами на макетах — аннотации, в интерфейс они не переносятся. Номер ведёт к пункту спеки и к шагу на схеме сценариев (например, «A3» — вариант A, отметка 3).

## Порядок работы

1. Этап 0 плана: ветка, ADR, скилл в `AGENTS.md`.
2. Этапы 1–2 — исправления безопасности и времени, их можно мержить отдельно и сразу.
3. Этапы 3–13 — редизайн по порядку, один этап — один коммит.
