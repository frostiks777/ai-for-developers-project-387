# Контракт с тестами

Редизайн меняет внешний вид, а **не** доступные имена элементов. Всё, что ниже, должно остаться, иначе упадут тесты в `src/**/*.test.tsx`. Автопроверку Хекслета (`.github/workflows/hexlet-check.yml`, чужие тесты) не видно, поэтому маршруты и ключевые тексты тоже не меняем.

## Что должно остаться

| Где | Селектор в тестах | Что соблюсти |
|---|---|---|
| `App.test.tsx` | `heading` «Календарь звонков» | Название продукта в шапке — `h1` (см. `design-spec.md`, §6) |

## Что меняется в тестах (разрешено)

1. `dashboard-page.test.tsx`, тест «не показывает телефон, если он не указан»: `closest('tr')` → `closest('li')` (брони теперь список карточек, а не таблица). Больше ничего в этом тесте не трогать.
2. Добавить новые тесты (см. `implementation-plan.md`): переключатель темы, лента дат на телефоне, авто-выбор первого свободного слота, фильтр «Все / Неделя / Сегодня», подсказка «≈ N слотов», счётчик комментария.
3. В `src/test/setup.ts` можно добавить заглушку `window.matchMedia` (по умолчанию `matches: false` для любых запросов, кроме `(min-width: 1024px)`, где `true`), чтобы тесты шли в десктопной раскладке. Для тестов мобильной раскладки подменять её локально.

Удалять или ослаблять существующие проверки нельзя.
