# Спецификация UI/UX приложения «Calendar» для ИИ-агента

Данный документ описывает экраны, формы, пользовательские сценарии, интерактивные элементы и схемы данных веб-приложения бронирования звонков.

---

## 1. Глобальная навигация (Header)

Отображается на всех экранах приложения в верхней части страницы.

| Элемент | Тип | Текст / Label | Поведение / Состояние |
| :--- | :--- | :--- | :--- |
| **Логотип / Название** | Ссылка / Brand | `Calendar` (с иконкой календаря) | Клик переводит на домашний экран (`/` или Screen 1). |
| **Кнопка вкладки 1** | Навигационная кнопка / таб | `Записаться` | Переход к процессу бронирования (Screen 2 / Screen 3). Имеет активное состояние (светло-серый фон pill-формы). |
| **Кнопка вкладки 2** | Навигационная кнопка / таб | `Предстоящие события` | Переход к просмотру созданных броней (Screen 6). Имеет активное состояние (серый фон). |

## 2. Экран 1: Главная страница / Лендинг (Screen: Landing)

*Референс: изображение 1 (`1EcovjeulRs0.jpg`)*

### Описание
Стартовая страница приложения. Презентует функционал и предлагает начать процесс записи.

### Элементы экрана
1. **Информационный бейдж:** Текст `БЫСТРАЯ ЗАПИСЬ НА ЗВОНОК` в скругленной плашке.
2. **Заголовок:** `Calendar` (h1).
3. **Подзаголовок:** `Один экран, понятные слоты, быстрая бронь. Выберите время и запишитесь на звонок без лишних шагов.`
4. **Основная CTA-кнопка:**

5. **Карточка «Что доступно прямо сейчас»:**

   - Пункт 2: `Проверка конфликта при бронировании.`
   - Пункт 3: `Просмотр предстоящих событий в отдельном разделе.`

## 3. Экран 2: Выбор даты и слота времени (Screen: Slot Selection)

*Референс: изображения 3 (`MN5Rcj0Hq1HV.png`) и 5 (`jWviXIUlXeYG.png`)*

### Описание
Трехколоночная структура бронирования под общим заголовком `Запись на звонок`.

### Блок 1: Панель «Информация» (Левая колонка)
Read-only информационная панель с текущими параметрами брони:
- **Выбранная дата:**
  - Название: `Выбранная дата`
  - Значение: Название дня недели и число (напр., `суббота, 28 марта` или `Не выбрано`).
- **Выбранное время:**
  - Название: `Выбранное время`
  - Значение: Диапазон времени `HH:MM - HH:MM` (напр., `09:00 - 09:30`) либо `Время не выбрано`.
- **Свободно:**
  - Название: `Свободно`
  - Значение: Число оставшихся свободных слотов на выбранную дату (напр., `18` или `17`).
- **Длительность в дне:**
  - Название: `Длительности в дне` (фиксированное значение)
  - Значение: `30 мин`.

### Блок 2: Интерактивный календарь (Центральная колонка)
- **Заголовок и управление месяцем:**
  - Название: `Календарь`.
  - Текущий месяц: Текст вида `март 2026 г.`.
  - Кнопки пагинации: `←` (Предыдущий месяц) и `→` (Следующий месяц).
- **Сетка дней:**
  - Заголовки дней недели: `Пн`, `Вт`, `Ср`, `Чт`, `Пт`, `Сб`, `Вс`.
  - Ячейки дней:
    - **Неактивные / недоступные дни:** Число месяца на сером фоне (напр., прошедшие дни `23`, `24`, `25`...).
    - **Активные доступные дни:** Отображают номер дня и подпись оставшихся слотов (напр., `28 / 18 св.`, `29 / 18 св.`).
    - **Выбранный день:** Выделен оранжевой рамкой и белым фоном (напр., день `28`).

### Блок 3: Выбор слота времени (Правая колонка)
- **Заголовок:** `Статус слотов`.
- **Список слотов:** Вертикальный список 30-минутных интервалов с 09:00:
  - Формат элемента: `[HH:MM - HH:MM] [Статус]`.
  - **Статусы слотов:**
    - `Свободно` (кликабельный, доступен для выбора).
    - `Занято` (некликабельный, серый текст, серый фон).
    - `Выбрано` (активный слот обведен оранжевой рамкой).
- **Кнопки управления шагом:**
  - Кнопка `Назад`: Вторичная кнопка (белый фон, серая рамка). Возврат на предыдущий шаг/лендинг.
  - Кнопка `Продолжить`:
    - **Состояние Disabled:** Блекло-оранжевый фон, если слот не выбран (`jWviXIUlXeYG.png`).
    - **Состояние Active:** Ярко-оранжевый фон, если выбран корректный слот (`MN5Rcj0Hq1HV.png`).
    - **Действие:** Переход к форме ввода контактных данных (Экран 3).

## 4. Экран 3: Форма персональных данных (Screen: Contact Form)

*Референс: изображение 2 (`d92bKoYDj0ZP.png`)*

### Описание
Двухколоночный экран оформления записи. Слева — сводка бронирования, справа — форма ввода имени и email.

### Блок «Подтверждение записи» (Форма)
- **Шапка формы:**
  - Заголовок: `Подтверждение записи`
  - Кнопка: `Изменить` (возвращает пользователя назад к выбору слота/календарю).
- **Поля ввода:**
  1. **Поле «Имя»:**
     - **Tag:** `<input type="text" />`
     - **Placeholder:** `Имя`
     - **Обязательность:** Обязательное (`required`).
     - **Валидация:** Непустая строка, допустимы текстовые символы.
  2. **Поле «Email»:**
     - **Tag:** `<input type="email" />`
     - **Placeholder:** `Email`
     - **Обязательность:** Обязательное (`required`).
     - **Валидация:** Валидный email-адрес (формат `username@domain.tld`).
- **Кнопка подтверждения:**
  - **Текст:** `Подтвердить запись`
  - **Стиль:** Основная акцентная оранжевая кнопка во всю ширину формы.
  - **Действие:** Отправка формы, фиксация брони в БД, переход на экран успеха (Экран 4).

## 5. Экран 4: Экран подтверждения бронирования (Screen: Success)

*Референс: изображение 4 (`t5QPzSarFLUt.png`)*

### Описание
Уведомление об успешной записи.
- Левая колонка обновляет счетчик слотов (было `18`, стало `17`).
- Правая колонка отображает статусное сообщение:
  - **Заголовок:** `Бронь подтверждена. До встречи!`
  - **Кнопка действия:** `Забронировать еще`
    - **Поведение:** Сбрасывает выбранные данные формы и переводит обратно на выбор времени (Экран 2).

## 6. Экран 5: Предстоящие события (Screen: Upcoming Events)

*Референс: изображение 6 (`esXHhgGyqbql.png`)*

### Описание
Список запланированных встреч пользователя/системы. В навигации активна вкладка `Предстоящие события`.

### Карточка события
Каждое созданное бронирование представлено отдельной белой карточкой со скругленными углами:
- **Заголовок / Имя клиента:** Жирный шрифт (напр., `Demo User 1774622445303`).
- **Email:** Серый текст под именем (напр., `demo-1774622445303@example.com`).
- **Слот (Дата и время):** `Слот: YYYY-MM-DD-HH:mm` (напр., `Слот: 2026-03-28-09:00`).
- **Дата создания записи:** `Создано: DD.MM.YYYY, HH:mm` (напр., `Создано: 27.03.2026, 14:40`).

## 7. Модель данных и API Contract для ИИ-агента

### 7.1. Модель бронирования (Booking Entity)
```json
{
  "id": "uuid-or-string",
  "client_name": "Demo User",
  "client_email": "demo@example.com",
  "slot_date": "2026-03-28",
  "slot_start_time": "09:00",
  "slot_end_time": "09:30",
  "slot_iso_formatted": "2026-03-28-09:00",
  "duration_minutes": 30,
  "created_at": "2026-03-27T14:40:00Z"
}
```

### 7.2. Пейлоад отправки формы (Submit Booking Request)
```json
{
  "date": "2026-03-28",
  "time_slot": "09:00 - 09:30",
  "name": "Иван Иванов",
  "email": "ivan@example.com"
}
```

### 7.3. Конечный автомат (FSM) шагов агента
1. `LANDING` $\rightarrow$ Клик по `Записаться →` $\rightarrow$ `SELECT_SLOT`
2. `SELECT_SLOT` $\rightarrow$ Выбор даты в календаре $\rightarrow$ Выбор доступного слота со статусом `Свободно` $\rightarrow$ Клик по `Продолжить` $\rightarrow$ `FILL_FORM`
3. `FILL_FORM`:
   - Заполнить поле `Имя`
   - Заполнить поле `Email`
   - Клик по `Подтвердить запись` $\rightarrow$ `SUCCESS`
   - *(Опционально)* Клик по `Изменить` $\rightarrow$ возврат в `SELECT_SLOT`
4. `SUCCESS`:
   - Клик по `Забронировать еще` $\rightarrow$ `SELECT_SLOT`
   - Клик по таб-меню `Предстоящие события` $\rightarrow$ `VIEW_EVENTS`
