# ADR 0016: Раздельные буферы до и после встречи

## Status

Accepted — 2026-09-25. Пункты 2 и 4 частично устарели: см. [ADR-0027](0027-slot-grid-step-independent-of-buffers.md) (2026-09-29).

## Context

`docs/archive/gemini-code-1790192589378.md` §3.1 требует два независимых перерыва между слотами: `buffer_before` и `buffer_after` (0–60 мин). В проекте был единственный `bufferMin`, который суммировался в шаг генерации слотов (`slotDuration + buffer`) и не различал перерыв до/после встречи.

## Decision

1. Заменяем `bufferMin` на два поля: `bufferBeforeMin` и `bufferAfterMin` (0–480) в настройках доступности и API-контракте (`AvailabilitySettings`, `UpdateAvailabilityRequest`).
2. ~~Шаг генерации слотов — `slotDurationMin + bufferBeforeMin + bufferAfterMin` (остаётся чистой функцией в `server/availability.ts`).~~ **Устарело:** по [ADR-0027](0027-slot-grid-step-independent-of-buffers.md) шаг сетки — только `slotDurationMin`, буферы применяются фильтром занятости.
3. БД: аддитивная миграция — колонки `bufferBeforeMin`/`bufferAfterMin` (`ADD COLUMN IF NOT EXISTS`, дефолт 0) и сохранён символ колонки `bufferMin` (дефолт 0). Бэкфилл: старый `bufferMin` переносится в `bufferAfterMin`, если тот ещё пуст.
4. Форма `/dashboard`: два поля «Буфер до, мин» и «Буфер после, мин»; подсказка «≈ N слотов в рабочем дне» считает шаг по сумме.
5. Легаси-схема `availability_rules` (`bufferMin`) остаётся только как носитель совместимости; в v1-ответах не участвует.

## Consequences

**+** Соответствие внешней спеке: независимые буферы до/после.
**+** Миграция не ломает существующие данные (бэкфилл в `bufferAfterMin`).
**−** Ломающее изменение контракта v1: поле `bufferMin` заменено парой `bufferBeforeMin`/`bufferAfterMin`; сгенерированный SDK и зеркала схем обновлены, внешние потребители должны мигрировать.
**−** Легаси-колонка `bufferMin` остаётся в схеме (мёртвая, но нужна для обратной совместимости старта).

## Alternatives considered

- **Оставить один `bufferMin`.** Отклонено: спека требует раздельные буферы, асимметричные перерывы — типичный кейс (например, 5 мин до / 15 мин после).
- **Отдельная таблица буферов.** Отклонено: избыточно для двух скаляров в одной строке настроек.
- **Не трогать БД, хранить сумму.** Отклонено: потеря независимости значений при чтении/редактировании.
