# ADR 0017: Парольный доступ к панели организатора

> **Superseded — 2026-09-29:** панель организатора открыта без логина, см. [ADR-0028](0028-dashboard-access-without-login.md). Гейт Basic-auth, `ADMIN_PASSWORD` и все защищённые маршруты из этого ADR удалены. Документ сохранён как история решения.

## Status

Superseded — 2026-09-29 (см. [ADR-0028](0028-dashboard-access-without-login.md)). До этого: Accepted — 2026-09-25. Пункт 6 в части публичного чтения `GET /api/v1/hosts/:slug/bookings` заменён [ADR-0022](0022-private-bookings-list.md) — 2026-09-28.

## Context

Панель организатора (`/dashboard`, `/admin/*`) была публичной: любой, кто знал URL, видел брони гостей, мог их отменять, менять доступность, типы встреч и блокировки. Для учебного проекта это недопустимо, но нужен компромисс: панель должна оставаться доступной наставнику Хекслета для проверки функциональности (см. `docs/todo.md`, Фаза 4).

Проект без пользовательских аккаунтов и без внешнего провайдера аутентификации; деплой — один контейнер на Render (Fastify + отданный `dist/`).

## Decision

1. `/dashboard`, `/admin` и `/admin/*` закрыты **HTTP Basic Auth** на уровне Fastify `onRequest`-хука.
2. Пароль читается из переменной окружения `ADMIN_PASSWORD` (zod-схема `server/env.ts`). Имя пользователя игнорируется — принимается любое.
3. Сравнение пароля — `crypto.timingSafeEqual` (константное время).
4. Если `ADMIN_PASSWORD` не задан — гейт выключен, панель открыта. Это сохраняет простой локальный dev, `npm test` и e2e (Playwright) без дополнительной настройки.
5. На деплое (Render) `ADMIN_PASSWORD` задаётся в `render.yaml`; демо-значение публикуется в README (раздел «Доступ организатора») — наставник входит по нему.
6. Под тем же Basic-auth закрыты и **административные API**: `PUT /api/v1/hosts/:slug/availability`, `POST/PATCH/DELETE /api/v1/hosts/:slug/event-types*`, `GET/POST/DELETE /api/v1/hosts/:slug/blocks*`, а также легаси `PUT /api/availability`, `GET /api/bookings`, `DELETE /api/bookings/:id`. Публичные чтения гостя остаются открытыми: `GET availability` (лендинг/бронь), `GET event-types` (выбор типа), `GET hosts/:slug/bookings` (страница `/events`), бронь и отмена/перенос по публичному id.
7. Вход в панель из SPA — **только полной навигацией** (`<a href="/dashboard">`), а не React Router `<Link>`: клиентский переход не идёт на сервер, поэтому Basic-запрос пароля не показывается. В `AppHeader` маршруты `/dashboard` и `/admin/*` рендерятся обычной ссылкой (`isAdminRoute`).

## Consequences

**+** Панель больше не публична «по умолчанию» в продакшене: без пароля в неё не войти.
**+** Наставник проверяет панель без дополнительной инфраструктуры: браузер сам показывает окно Basic-auth, логин/пароль есть в README.
**+** Ноль новых зависимостей и ноль изменений фронтенда — браузер кэширует Basic-креденшелы и подставляет их в same-origin запросы к `/api/v1/*`.
**−** Демо-пароль лежит в открытом репозитории (README, `render.yaml`), то есть от настоящего злоумышленника не защищает — осознанная плата за проверяемость курсового стенда.
**−** Нативный диалог Basic-auth нельзя стилизовать; UX отличается от остального интерфейса.
**−** Публичные чтения (брони, типы встреч, доступность) остаются открытыми по дизайну — их используют гостевая бронь и страница `/events`; это осознанный компромисс, а не недосмотр.
**−** SPA-переход по `<Link>` обошёл бы Basic-auth (браузер не ходит на сервер) — вход в панель пришлось сделать полной навигацией; это ограничение нужно помнить при добавлении новых ссылок на `/dashboard` и `/admin/*`.

## Alternatives considered

- **Клиентский экран входа с запросом к серверу и токеном в localStorage.** Отклонено: без серверной проверки на каждом админ-эндпоинте это косметика, а полноценные сессии/куки — заметно больший объём ради учебного MVP.
- **Сессии + `@fastify/session`/JWT.** Отклонено: лишняя инфраструктура и зависимости; Basic-auth даёт ту же защиту панели «из коробки».
- **Оставить панель публичной, полагаясь на «секретный» URL.** Отклонено: URL уже раскрыт (кнопка в шапке, README), и это не контроль доступа.
- **Убрать кнопку/маршрут панели вовсе.** Отклонено: ломает сценарий проверки наставником и работу организатора.
