# ADR 0007: Визуальный редизайн (A + D) и светлая/тёмная тема

> Номер изменён с 0006 на 0007 при переносе пакета дизайна: ADR-0006 уже занят
> решением «Отмена брони по токену-ссылке».

## Status

Accepted — 2026-09-23. (Ветка `feat/redesign-a-d-themes` смержена в `main`.) Дополнен [ADR-0023](0023-redesign-v2-mint.md) — раскладки и токены v2 заменяют визуальный слой v1.

## Context

Интерфейс собран на стандартной нейтральной теме shadcn: одна узкая колонка, слоты — карточки с кнопкой «Забронировать» на каждой, бронирования организатора — таблица. На телефоне экран выглядит так же, как на десктопе, тёмной темы нет. Спека (`docs/code_artifact.md`, §3) описывает страницу бронирования из трёх колонок (инфо — календарь — слоты) и выбор часового пояса. Было предложено четыре варианта дизайна. Утверждены вариант A для десктопа и вариант D для телефона, обе раскладки — в светлой и тёмной темах.

## Decision

- Десктоп (≥ 1024 px): три колонки по спеке — инфо об организаторе и встрече, календарь месяца, сетка слотов; выбранный слот раскрывается в «время + Забронировать».
- Телефон (< 1024 px): лента доступных дат, сетка слотов в 3 колонки, закреплённая нижняя панель с выбранным временем, форма брони — панель снизу экрана.
- При выборе даты автоматически выбирается первый свободный слот.
- Единые токены (shadcn, HSL) для двух тем; тема переключается классом `.dark`, выбор хранится в `localStorage`, по умолчанию берётся системная тема, inline-скрипт в `index.html` убирает мигание.
- Шрифты Golos Text (интерфейс) и Lora (заголовки) через `@fontsource`.
- Раскладка выбирается хуком `useMediaQuery`, а не скрытием через CSS, чтобы в DOM не было дублей.
- Панель организатора: список броней по дням вместо таблицы и компактная форма доступности рядом со списком.
- Детали: `docs/design/`.

## Consequences

- (+) Страница бронирования соответствует спеке; на телефоне удобнее (крупные цели, одно нажатие до формы).
- (+) Появилась тёмная тема; цвета заданы только токенами, контраст ≥ 4.5:1.
- (+) Бэкенд и API не меняются.
- (−) Две раскладки гостевой страницы — больше кода и тестов на мобильную ветку.
- (−) Два новых npm-пакета со шрифтами (~100 КБ woff2 на подмножество кириллица + латиница).
- (−) Данных об организаторе нет в API — временно константы в `src/config/host.ts`.

## Alternatives considered

- **B — пошаговый мастер.** Проще для гостя, но на один шаг длиннее, и на десктопе много пустого места.
- **C — вся неделя на одном экране.** Быстро выбрать время, но плотный интерфейс и плохо переносится на телефон.
- **Одна адаптивная раскладка через CSS.** Дубли календаря в DOM ломают тесты и доступность.
- **next-themes.** Лишняя зависимость ради ~40 строк кода; в проекте нет Next.js.
