# ADR 0019: «Мои встречи» на устройстве (локальное сохранение брони)

## Status

Accepted — 2026-09-25.

## Context

Отмена/перенос у гостя — capability по секретному токену в ссылке ([ADR-0006](0006-cancellation-by-token.md), [ADR-0008](0008-reschedule-by-token.md)). Аккаунтов нет, почтового провайдера нет. Если гость закрыл экран успеха, не скопировав ссылку, вернуться к своей брони невозможно — UX-дыра.

Нужен способ найти свою встречу без ссылки, не вводя аккаунты и не создавая риск перечисления чужих броней по email.

## Decision

1. При успешном бронировании сохраняем запись в `localStorage` браузера (`call-calendar-my-bookings`): `{ id (он же cancelToken), startAt, durationMin, eventTypeTitle, hostSlug }`. Логика — `src/utils/my-bookings.ts` (try/catch, дедуп по id, максимум 50 записей).
2. Страница `/my` («Мои встречи») показывает сохранённые брони с датой/временем и действиями: «Перенести» (`/reschedule/:id`), «Отменить» (`/cancel/:id`), «Убрать из списка» (удаление локально).
3. Навигация: третья вкладка «Мои встречи» в шапке (лендинг, `/book/:slug`, `/events`, `/booking/:uuid/confirmed`, `/my`).
4. Прошлые встречи помечаются бейджем «Прошла», но остаются в списке, пока пользователь их не уберёт.

## Consequences

**+** Гость может отменить/перенести встречу без ссылки, пока пользуется тем же браузером.
**+** Ничего не утекает на сервер: токен хранится только локально, нет перечисления по email.
**+** Ноль изменений API/БД, работает поверх существующих cancel/reschedule.
**−** Не помогает при смене устройства/браузера, очистке хранилища или приватном режиме — это ограничение capability-модели без аккаунта/почты, а не баг.
**−** localStorage может быть недоступен (приватный режим) — тогда список просто пуст; бронь не теряется на сервере, но удобство недоступно.

## Alternatives considered

- **Поиск броней по email без верификации.** Отклонено: любой по чужому email увидит и отменит встречи (перечисление). Небезопасно без подтверждения.
- **Письмо со ссылками при бронировании.** Отклонено на этом шаге: нужен почтовый провайдер (SMTP/Resend) и ключи; можно добавить позже как дополнение.
- **Аккаунты гостя.** Отклонено: противоречит лёгкому гостевому флоу проекта, избыточно.
