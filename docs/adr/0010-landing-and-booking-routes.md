# ADR 0010: Главная страница (лендинг) и маршрут бронирования `/book/:slug`

## Status

Accepted — 2026-09-24.

## Context

Курс требует «главную страницу, которая рассказывает про сервис и ведёт на запись». До этого `/` сразу отдавал экран бронирования (календарь и слоты), а витрины у сервиса не было. Внешняя спека ([`docs/archive/gemini-code-1790192589378.md`](../archive/gemini-code-1790192589378.md), §1.1) закладывает публичный маршрут `/book/:slug`. Нужно было решить, где живёт лендинг и куда переезжает бронирование, не ломая существующие ссылки и Hexlet-автопроверку главной.

## Decision

- `/` — новая **главная страница** (`LandingPage`): витрина для гостя (hero, «Как это работает», карточка организатора, CTA).
- `/book/:slug` — **страница бронирования** (перенесённый `HomePage`).
- Данные лендинга — только `GET /api/v1/hosts/:slug/settings` (имя, длительность); `meetingTitle`/`format` остаются статикой в `src/config/host.ts`.
- `slug` хранится в `src/config/host.ts` (`host.slug = 'default'`); неизвестный slug на `/book/:slug` → `NotFoundPage`.
- Ссылки «к бронированию» (дашборд, страницы отмены/переноса) ведут на `/book/${host.slug}`.
- Фронт брони переходит на API v1 (`/api/v1/hosts/:slug/slots`); легаси `/api/*` остаётся для дашборда и тестов.

## Consequences

(+) У сервиса появилась витрина, а маршрут брони совпал со спекой и готов к мульти-хосту.
(+) Разделение ответственности: лендинг — витрина без списка слотов, бронь — рабочий экран.
(+) Автопроверка Hexlet (ответ на `/`) продолжает получать 200.
(-) Изменились маршруты: старые ссылки на `/` как на бронь больше не работают, нужно было обновить страницы отмены/переноса и тесты.
(-) Лендинг зависит от доступности API: при ошибке показывает имя из конфига (graceful fallback).
(-) `meetingTitle`/`format` дублируют будущую сущность «тип встречи» — заменим на Шаге 2.

## Alternatives considered

- **Лендинг на `/about`, `/` оставить бронированием** — не выполняет формулировку курса («главная ведёт на запись») и не совпадает со спекой.
- **Вводный блок над календарём на `/`** — перегружает рабочий экран, лендинг не отделён от брони.
- **Лендинг без API (только конфиг)** — отклонено: пользователь выбрал источник данных из API.
- **Сразу полная мульти-хост-модель** — выходит за рамки шага; сделан аддитивный слой `hosts` + `/api/v1`.
